關於「香港公廁資訊」

非官方公民資訊工具 · 資料每次載入時即時讀取自政府開放數據

本網站整合香港食物環境衞生署（FEHD）轄下公廁、旱廁、公共浴室及長期擺放的流動廁所的官方位置資料，方便市民在地圖上查閱。

資料來源

  • data.gov.hk － FEHD facility and service locations（資料集頁面）
  • 食環署原始 XML 資料（繁體中文）
  • 食環署設施地圖官方網站

資料涵蓋範圍

本網站只篩選並顯示與洗手間相關的四類設施：公廁、旱廁、公共浴室、長期擺放的流動廁所。每個地點的名稱、地址、開放時間及聯絡電話均直接來自上述官方資料，並顯示食環署最後更新該筆資料的日期。

目前未能提供的功能

經查核 data.gov.hk 及食環署現有的公開資料集，暫時沒有提供：

  • 個別公廁的即時使用人流／擠塞程度數據
  • 公廁現場即時影像或相片的公開 API

因此網站會在相關位置清楚註明「暫無官方資料」，不會以虛構內容填補。網站另會嘗試從食環署備註欄（例如「暫停服務日期」）推斷該處目前是否正常開放，此資訊同樣直接來自官方資料。
